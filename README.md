# Sistema de Soporte a la Decisión (DSS) en Desarrollos Inmobiliarios

Analizar el mercado inmobiliario a nivel nacional es un reto debido a la enorme diferencia de precios que existe entre regiones. Para resolver esto, se diseñó una estrategia en tres fases:

**Objetivo:**
Desarrollar un sistema de apoyo a la toma de decisiones en el sector inmobiliario para la toma de deci-
siones, identificando clústeres de valor y optimizando los precios, mediante técnicas de ciencia de datos, con
el fin de llegar a una meta de rentabilidad definida por el mismo proyecto.

Etapa 1 - Segmentar conforme a la ubicación y el precio de mercado. Las características físicas van a permitir diferenciar los tipos de inmueble dentro de cada nivel de mercado.

Etapa 2 — Predicción de precio conforme sus características físicas (como los metros cuadrados, número de habitaciones o baños). Al haber separado las zonas en el paso anterior según las características, el cálculo del precio se vuelve mucho más preciso.

Etapa 3 — Optimización, se toman esas estimaciones y junto con reglas financieras, se ajusta según las restricciones de un proyecto en específico.
